# Измерение скорости скачивания

Консольный скрипт выполняет 10 последовательных GET-запросов
к указанному URL. Каждый ответ скачивается полностью.

## Требования

Python 3.9 или новее. Сторонние библиотеки не используются.

## Запуск приложения

```bash
python app.py "https://example.com/large-image.jpg"
```

В зависимости от системы вместо `python` может понадобиться `python3`.

## Результат

Скрипт выводит:

- среднее время запроса в секундах;
- общий объём скачанных тел ответов в байтах;
- скорость скачивания в МиБ/с (1 МиБ = 1 048 576 байт).

Расчёт:

- среднее время = сумма длительностей запросов / 10;
- скорость = общий объём / сумма длительностей запросов.

Время измеряется от начала открытия соединения до полного чтения
и закрытия ответа. Так результат учитывает установление соединения
и ожидание сервера, а не только передачу данных.

Объём учитывает тела ответов, без HTTP-заголовков и сетевых накладных
расходов. Серверу отправляется `Accept-Encoding: identity`,
чтобы запросить ответ без HTTP-сжатия.

## Особенности

- Данные читаются порциями по 64 КиБ и не сохраняются на диск.
- HTTP-перенаправления обрабатываются автоматически.
- Тайм-аут блокирующих сетевых операций — 30 секунд.
  Это не ограничение общей длительности скачивания.
- При сетевой ошибке или HTTP-ошибке, например 404 или 500,
  скрипт прекращает работу с кодом 1, не выводя итог для неполной серии.

Полученное значение характеризует скачивание с конкретного сервера,
а не максимальную пропускную способность интернет-соединения.
